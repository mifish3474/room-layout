# Room Layout Tool

A simple classroom room-mapping tool designed to help create printable setup maps for classroom maintenance and summer reset.

## Features

* Drag-and-drop furniture placement
* Snap-to-grid movement
* Rotatable objects
* Resizable objects
* Adjustable walls with angled support
* Custom objects with custom colors and labels
* Printable room maps with legend
* Downloadable save files
* Browser autosave support
* Measurement display toggle

## Basic Use

### Add Items

Use the toolbar buttons to add furniture, walls, text boxes, or custom objects.

### Move Items

Click and drag any object to reposition it on the grid.

### Rotate Items

Click the rotate button (↻) on an object to rotate it.

### Resize Items

Drag the red resize handle to change dimensions.

### Duplicate Items

Use the duplicate button (⧉) to quickly copy objects with the same size and settings.

### Walls

Walls can:

* Be dragged
* Be resized from either endpoint
* Snap to the grid
* Be angled for irregular room shapes

### Measurements

Use the “Measurements” button to toggle dimension labels on/off.

### Saving

#### Browser Save

* Click **Save** to save locally in the browser.
* Click **Load** to reload the browser save.

#### Downloadable Save File

* Click **Download Save File** to export a `.json` layout file.
* Click **Load Save File** to import a saved layout on another computer.

### Printing

Click **Print** to generate a printable room map.

For best results:

* Turn ON “Background Graphics” in the print dialog.
* Turn OFF measurements before printing if the labels clutter the map.

## Notes

* Grid size is based on 1 square = 1 foot.
* Objects snap to the grid automatically.
* Works best in Chrome or Edge.
* Designed primarily for classroom setup planning and maintenance maps.
